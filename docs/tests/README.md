## 统一口径

- 关闭：移除 SkillX 的模型发现和执行入口；开启：通过公开契约及 `capability_run` 执行。
- Token 包含未缓存输入、缓存读取、输出；完整调用包含发现、失败、恢复及最终答复，提取与修订另列。
- 耗时使用原生会话起止墙钟。中止记录明确为未完成，用量可能是下限，不据此计算完整成功收益。
- 同一表格注明模型、任务、环境、顺序、样本数和是否复用旧能力；历史对照不冒充同轮实验。
- 成功必须有真实业务产物和独立核验。静态发布、DAG 图和成功回执不能单独证明行为正确。
- 不发布私有会话正文或凭据。结构化汇总可入仓，完整原始证据仅保留在报告注明的本机目录。

## 维护规则

同一场景更新现有报告，必要时补充带日期的小节；只有任务或验证目标不同才新建主题目录。报告至少说明结论、条件、结果、计费范围和局限。失败与未完成样本保留摘要，不仅展示成功均值。自动化回归的范围和运行方法见 [tests/README.md](../../tests/README.md)。
