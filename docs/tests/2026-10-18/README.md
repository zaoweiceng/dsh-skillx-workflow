# 2026-10-18 GPT-5.5 medium 调用与提取测量

## 调用条件

三组开启与关闭对照均使用 GPT-5.5、medium 推理档位，通过已接入 DSH 原生工具调用和用量回报的模型提供方执行。每次创建独立会话和隔离 Git 仓库，初始 HEAD、文件改动和待处理路径相同。业务参数一致，文件系统路径随隔离目录变化。

任务为创建分支、仅提交指定文件、推送到本机 bare 远端并创建模拟 MR。工作目录包含空格和单引号，CLI 路径和 Node PATH 前缀包含空格；提交正文和 MR 正文包含美元表达式、命令替换、反引号和引号。

开启组复用同一已发布工作流，通过 SkillX 发现并调用 `capability_run`。关闭组通过 `enableCapabilities=false` 移除 SkillX 发现与执行入口。普通 Skill 和原生工具在两组均可用。六次调用串行执行，顺序为开启/关闭、关闭/开启、开启/关闭；模型缓存保持自然状态。

Token 口径为 DSH 报告的未缓存输入、缓存读取和输出之和。开启组三次累计为输入 134,109、缓存读取 69,120、输出 1,871；关闭组三次累计为输入 521,026、缓存读取 130,560、输出 12,233。金额取决于提供方的输入、输出和缓存定价。

## 结果质量

两组各三次均完成一次提交、一次本机远端推送和一次模拟 MR 创建。实际提交仅包含指定的两个文件，保留目录内容完整；提交正文和 MR 正文逐字一致；分支、完整提交 SHA、MR 编号、链接及目标分支与实际执行结果一致。

开启组三次均应用指定的 PATH 前缀，关闭组三次均遗漏该参数。实验环境已有可用 Node，六次交付均成功；这项差异体现了参数遵循情况与交付成功率的区别。

开启组每次加载一次 SkillX 并调用一次工作流，使用三次模型请求完成发现、参数准备和最终汇报。工作流内部执行六个确定性工具步骤，三次耗时分别为 1.053、0.719、0.951 秒，内部模型用量为 0。关闭组加载普通 CLI 或交付说明，自行选择 shell 操作和验证步骤。

## 提取测量

下表使用同一冻结来源的既有单次提取测量，调用对照复用该产物。模型配置、独立生成的验收契约和实现版本按各样本记录。

| 提取样本 | 模型及推理档位 | 耗时 | Token |
|---|---|---:|---:|
| DeepSeek 参考样本 | DeepSeek Flash Low | 1,891.506 秒 | 326,295 |
| GPT-5.5 对照样本 | GPT-5.5 medium | 163.817 秒 | 239,207 |
| 本次实现样本 | GPT-5.5 medium | 127.348 秒 | 166,044 |

两个 GPT-5.5 样本相比，耗时减少 22.26%，Token 减少 30.59%。与 DeepSeek 参考样本相比，分别减少 93.27% 和 49.11%。这些数值反映具体运行条件下的测量；模型档位、验收要求和实现版本共同影响结果。

本次实现样本在一个任务内自主完成规划、契约、实现、局部修复、验收和发布。六次模型请求中包含一次契约纠正和两次实现修复，最终 18 项验收通过。阶段成本如下：

| 阶段 | 耗时 | Token |
|---|---:|---:|
| 职责规划 | 15.328 秒 | 23,254 |
| 验收契约 | 60.030 秒 | 58,101 |
| 实现与局部修复 | 51.943 秒 | 84,689 |

提取 Token 明细为输入 104,695、缓存读取 46,080、输出 15,269。该单次成功样本证明了此案例的自主完成能力；稳定成功率需要更多独立提取样本。

## 数据与适用范围

[comparison.json](comparison.json) 保存逐次用量、工具调用数量、结果检查、工作流执行耗时及提取测量。调用数据覆盖完整对话，包括能力发现、工具执行和最终汇报；提取成本单独统计。

实验使用隔离仓库、本机远端和模拟托管结果，来源仓库的 HEAD、工作区和 refs 哈希保持一致。三组调用是单一任务的小样本描述性对照，服务负载和缓存会影响耗时。另有 [DeepSeek Flash High 实验](../2026-10-14/README.md)，其任务包含模拟 MR 合并和回读核验，各批结果按其自身条件解释。
