Stages all pending changes (git add -A) in a local repo and creates exactly one commit with a fixed message on the current branch. It verifies the exact staged file set, a clean working tree, a single commit whose parent equals the pre-commit baseline, and absence of git remotes. It never pushes, never creates branches, and performs no hosting/remote operations. Inputs generalize the repo path, message, expected file set, and baseline ref; all checks are re-run on every invocation. Fails closed on configured remotes, empty or mismatched staged set, dirty tree, or parent/baseline mismatch.
